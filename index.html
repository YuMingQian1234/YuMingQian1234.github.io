01

关于我

About

好的研究，既要能解释问题，也要能跑起来。

我是 Mingqian Yu，中国科学院自动化研究所的硕士研究生，本科毕业于东北大学（NEU, China）。目前的研究兴趣集中在 LLM Pretraining、Looped Transformer 与高效推理。

最近的一作工作包括 T-LoopFormer 与 ContraFM-S2O：前者研究 token 级别的弹性循环深度，让每个 token 自己决定循环多少次，并用递归级 KV Cache 加速自回归解码；后者用单步流匹配与对比学习做 SAR-to-optical 图像翻译，降低扩散模型的推理延迟。

另一条线是 SportsCom —— 一个大规模、多运动、多类别、多属性的体育解说数据集，用于评测 MLLM 对长视频叙事与战术的理解。我也在开源模型上做实践，复现和调试 VILA 系列视频语言模型。

欢迎交流论文、数据集、实习机会，或任何关于大模型预训练、推理与生成模型的想法。
